# T2-AI-TASK1. 
1. Project Introduction

This project presents a comprehensive data science and artificial intelligence system. It covers the entire workflow, from data understanding and preprocessing to advanced visualization and feature engineering. The project culminates in a high-performance machine learning model integrated into an interactive web application, reflecting industry-standard practices in AI development.

2. Dataset Description

The system is built using the YouTube Videos Data for ML and Trend Analysis dataset from Kaggle. It contains rich metadata for over 20,000 videos, including titles, descriptions, categories, and engagement metrics (views, likes, comments). This large-scale dataset was used to ensure the model's reliability and to support deep analytical insights.

3. GitHub Repository Structure

The repository is organized to facilitate collaboration and transparency:

Datasets: Raw and processed data files.

Notebooks: Step-by-step code for cleaning, visualization, and feature engineering.

Models: Trained machine learning models with optimized hyperparameters.

Web Source Code: The complete source code for the interactive deployment.

4. Website Overview

We have developed an interactive website to make our findings and models accessible.

Technology Stack: Built using Python and Streamlit.

Visuals: Integrated with Plotly for dynamic and interactive dashboards.

Deployment: The machine learning model is live on the site, providing real-time predictions.

5. Website Pages

Page 1: Project Information: Provides a detailed overview of the dataset, our methodology, and the business problems we solved.

Page 2: Visualization & Feature Engineering: Features interactive heatmaps and scatter plots. It explains the transformation techniques (like Log Scaling) used to enhance data quality.

Page 3: AI Model & Predictions: The core of the application. It allows users to input video metadata and receive instant view count predictions based on our optimized HistGradientBoosting model, which achieved an R² score of over 0.84.
