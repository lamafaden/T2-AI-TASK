## 1. Project Introduction
This project simulates a real-world data science and artificial intelligence workflow.  
It covers the main stages of a data-driven system, starting from data understanding and preprocessing, followed by data visualization and feature engineering.  
Machine learning modeling and an interactive website are planned as part of the later phases of the project.

The project emphasizes technical implementation, analytical thinking, teamwork, and professional documentation, reflecting academic and industry-oriented data science practices.

---

## 2. Dataset Description
The dataset used in this project is **YouTube Videos Data for ML and Trend Analysis**, obtained from Kaggle.  
It contains metadata about YouTube videos, such as titles, descriptions, categories, views, likes, comments, and other related features.

The dataset includes **more than 20,000 rows**, satisfying the project data size requirement.

### Why this dataset was chosen:
- Represents a real-world scenario related to online content and user engagement
- Large enough to support meaningful visualization and analysis
- Contains multiple numerical and categorical features
- Suitable for trend analysis and future machine learning applications

### What the data represents:
The data reflects real-world YouTube video performance and engagement patterns, enabling exploration, visualization, and predictive modeling.
